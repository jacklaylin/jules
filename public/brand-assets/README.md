# Style collage logo assets

Reviewed assets are mapped by exact brand name in `../brand-assets.js`. Unknown brands are omitted from the visual collage rather than rendered as imitation wordmarks. These marks identify the brands supported by the user's evidence; they do not imply sponsorship.

- Sown Again: official site header, https://sownagain.com/cdn/shop/files/Untitled_design_86.png?v=1774903076 (https://sownagain.com/).
- Oakley: https://commons.wikimedia.org/wiki/File:Oakley_logo.svg, attributed to Oakley; public-domain text/geometric mark, trademark retained.
- adidas Originals: https://commons.wikimedia.org/wiki/File:Original_Adidas_logo.svg, attributed to Adidas, citing Adidas Group's roadshow PDF. Trademark retained.
- SSENSE: https://commons.wikimedia.org/wiki/File:Ssense_logo.svg, attributed to SSENSE with ssense.com as source; public-domain text mark, trademark retained.

Web stories and PNG exports use these same local files.
